# OFFROU 앱 아이콘 — ⚠️ 임시(placeholder)

이 폴더의 아이콘은 **확정된 OFFROU 로고가 아니다.** 1단계에서 만든 임시 그림(길 + 점)을 각 플랫폼 크기로 옮긴 것이다.
실제 로고가 정해지면 아래 파일을 **같은 이름·같은 크기**로 교체한다 (manifest·index.html은 수정할 필요 없음).

| 파일 | 크기 | 용도 | 비고 |
|---|---|---|---|
| `icon-192.png` | 192×192 | 안드로이드 홈 화면·설치 대화상자 | 모서리 여백 포함 일반 아이콘 |
| `icon-512.png` | 512×512 | 안드로이드 스플래시·스토어형 큰 아이콘 | 일반 아이콘 |
| `icon-maskable-512.png` | 512×512 | 안드로이드 적응형(원·물방울 등으로 잘림) | **가운데 80% 안에** 로고를 두고 배경을 꽉 채운다 |
| `apple-touch-icon.png` | 180×180 | iPhone·iPad 홈 화면 | 투명 배경 금지, 모서리는 iOS가 둥글게 깎는다 |
| `favicon-32.png` | 32×32 | 브라우저 탭 (SVG 미지원 브라우저용) | |
